INTERACTIVE MATH CALCULATOR

Files:
- index.html  : Calculator interface
- style.css   : Attractive responsive styling
- script.js   : Addition, subtraction, multiplication, division,
                validation, and calculation history

How to run:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html using Live Server, or open index.html directly in a browser.

Features:
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Division-by-zero validation
- Clear button
- Calculation history
- Responsive design
- Interactive operation buttons
- Modern card-based UI
