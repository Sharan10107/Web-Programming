# Book Library Website

A simple responsive book information website built using HTML, CSS and JavaScript.

## Features

- Home page with multiple books
- Click any book to open its information page
- Displays author, category, price, rating and description
- Responsive design for mobile and desktop
- JavaScript connects the home page and details page using URL parameters

## Files

- index.html - Home page
- book.html - Book details page
- style.css - Website styling
- script.js - Book data and page navigation

## How to run

1. Extract the ZIP file.
2. Open the `book-website` folder.
3. Double-click `index.html`.
4. Click any book to see its details.

You can also open the folder in VS Code and use Live Server.
