MYCOLLEGE UNIVERSITY WEBSITE

PROJECT FILES
index.html       Home page
courses.html     Programme catalogue
highlights.html  University highlights
campus.html      Campus and facilities
events.html      Academic dates and events
contact.html     Contact details and admissions form
style.css        Shared responsive styles
script.js        Navigation, reveal, back-to-top and form behavior
images/          Local JPG assets used by the hero and campus pages

RUN THE WEBSITE
Open index.html directly in a browser, or open this folder in VS Code and choose
"Open with Live Server" from index.html. The page links and local images use
relative paths, so the other pages work from the same folder.

The contact form validates entries in the browser but does not send them to a
server. Google Fonts are loaded from Google Fonts when an internet connection is
available; system font fallbacks are included.
