BOOK INFORMATION WEBSITE (INTERACTIVE EDITION)
=================================================

Project: Interactive Book Information Website using HTML Frames & JavaScript

FILES:
------
index.html   - Main page containing the frameset layout
books.html   - Left frame containing the interactive book catalog with live search & filters
home.html    - Right frame welcome & interactive reading dashboard
book1.html   - The Alchemist interactive information & audio narration
book2.html   - Atomic Habits interactive information & audio narration
book3.html   - Rich Dad Poor Dad interactive information & audio narration
book4.html   - Harry Potter interactive information & audio narration
style.css    - Modern CSS design system, typography, and dark/light themes
shared.js    - Shared JavaScript engine (localStorage, Web Speech TTS, Toast system, Tab engine)

INTERACTIVE FEATURES:
---------------------
1. Live Search & Category Filtering:
   - Instant real-time search across book titles, authors, and genres in the sidebar.
   - Filter chips for Fiction, Self-Help, Finance, Fantasy.

2. Web Speech AI Audio Narration:
   - "Listen to Overview" Text-to-Speech narration with Play, Pause, and Stop controls and speed adjustments.

3. 5-Star Rating System:
   - Interactive star rating widgets on detail pages that persist in localStorage.

4. Reading Status & Favorites:
   - "Want to Read", "Currently Reading", and "Completed" status selectors.
   - 1-click Favorite heart toggle with live syncing between sidebar and detail pages.

5. Reading Progress Tracker:
   - Interactive slider tracking percentage and pages read.

6. Tabbed Information Views:
   - Overview: Synopsis, publication details, and ratings.
   - Key Takeaways: Interactive checklist of core lessons.
   - Memorable Quotes: Interactive cards with 1-click "Copy Quote" clipboard action.
   - My Notes: Autosaving personal reflections notepad stored in localStorage.

7. Interactive Dashboard (home.html):
   - "Surprise Me" random book generator.
   - Live Reading stats counter.
   - Daily Quote Generator with shuffle button.
   - Book Recommendation Finder / Quiz.

8. Dark & Light Theme:
   - Built-in theme switcher with persistence.

HOW TO RUN:
-----------
1. Open index.html in any modern web browser (Chrome, Edge, Firefox).
2. Select any book from the left sidebar to open its details in the right frame.
3. Enjoy the interactive audio, ratings, notes, and search capabilities!
